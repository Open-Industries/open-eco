# Domain Standards — Environmental Management

Alignment mapping for this core. *Aligned to* throughout: inventories produced with this
core still require organizational boundary setting and, where applicable, accredited
third-party verification (ISO 14064-3) — neither is claimed here.

## Concept mapping

| Platform concept | Domain standard | Mapping |
|---|---|---|
| Emission sources & categories | ISO 14064-1 / GHG Protocol | Source types and Scope 1/2/3 entry categories |
| Carbon budgets | ISO 14001 planning / internal carbon governance | Guarded budget accounts; the no-overrun invariant |
| Sustainability rules | ISO 50001 (energy) + category policies | Rules context with reasoned decisions |
| Offset projects | Voluntary carbon market practice | Catalogue only; credit issuance/retirement stays with registries |
| Evidence | ISO 14064-3 verification readiness | Append-only records, audit logging |

## Scope boundaries

This core does not verify emissions, issue carbon credits, or file regulatory reports.
It keeps the organization's internal accounting disciplined and auditable.
